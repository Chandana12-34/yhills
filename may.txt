The browser-based health dashboard is now calling actuator endpoints directly using JavaScript fetch().

Some services are failing due to missing CORS headers.

Please enable CORS for actuator endpoints by adding:

management:
  endpoints:
    web:
      cors:
        allowed-origins:
          - "http://localhost:8501"
        allowed-methods:
          - GET

Affected services:
- E2E Tracker
- Case Manager
